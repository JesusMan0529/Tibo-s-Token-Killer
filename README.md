<h1 align="center">Tibo's Token Killer</h1>
<p align="center"><strong>趁 Tibo 还没摸到按钮之前榨干你所有的额度！</strong></p>

Codex 额度任务助手是一位不用喝咖啡的值班同事。把任务交给它，电脑开着时，它会每 15 分钟查看一次 Codex 额度；额度可用，就在你指定的文件夹里继续工作。额度暂时用完，它等下一轮；任务做完，它会收工，不会反复提交同一份作业。

想持续处理一系列工作？勾选「持续任务」，它会做完一个阶段，再检查额度并接着做下一个。想看它有没有偷偷摸鱼？双击实时状态面板，就能看到当前状态、最近进度和额度记录。整个插件使用 Python 标准库，不需要 API Key 或额外的 Python 包。

## 安装和使用

需要 **Windows、Python 3.10 或更新版本（含 Tkinter）、已登录的 Codex CLI**。安装脚本会调用 `python.exe`、`pythonw.exe` 和 `codex.exe`；打开 PowerShell 后，先确认这两个命令能显示版本：

```
python --version
codex --version
```

本项目已在 Codex CLI `0.159.0-alpha.12.1` 上验证。

1. 在这个 GitHub 仓库页面点击绿色 **Code** 按钮，再点 **Download ZIP**。解压后，打开那个能直接看到 `安装.ps1` 和 `打开设置面板.vbs` 的文件夹。把文件夹放在准备长期保留的位置。
2. 在该文件夹的地址栏输入 `powershell` 并按回车。在打开的窗口中粘贴以下命令，按回车安装：

   ```
   powershell -NoProfile -ExecutionPolicy Bypass -File .\安装.ps1
   ```

   安装会注册插件和每 15 分钟运行一次的 Windows 定时任务。首次安装时开关默认关闭，也没有预设任务。
3. 关闭并重新打开 Codex。在 PowerShell 中输入 `codex` 进入 Codex CLI，再输入 `/hooks`；找到 **Codex 额度任务助手** 的 `UserPromptSubmit` 钩子，查看内容并选择信任。聊天口令在这一步后才会生效。[Codex 官方钩子说明](https://learn.chatgpt.com/docs/hooks)
4. 双击 `打开设置面板.vbs`。在「目标任务」写清要做什么，例如“修复这个项目里失败的测试，运行测试并报告结果”；在「任务工作目录」选择该项目所在的文件夹。要持续处理一系列工作，就先勾选「持续任务」。然后点击 **保存目标任务**。
5. 在 Codex 聊天中，把 **`不要让Tibo发现`** 作为一整条消息单独发送，开启监控。它会立即检查一次额度，之后每 15 分钟检查一次。口令可以有首尾空白，但不要加引号、说明文字或其他内容。
6. 双击 `打开实时状态.vbs` 查看它在工作、等额度，还是需要你处理问题。这个窗口只读取本地状态；关闭窗口不会停止监控。
7. 想停止时，把 **`Tibo要按按钮了`** 作为一整条消息单独发送。单次任务会请求立即中断；持续任务会完成当前正在处理的项目后停止，不再开始下一个项目。若额度耗尽时聊天框无法发送消息，双击第 4 步的设置面板，点击 **关闭**。

电脑需要保持开机并登录 Windows，睡眠或关机期间不会检查额度。任务遇到需要人工处理的问题时会停下来；处理好以后，再用开启口令继续原来的任务。请保留解压后的源码文件夹，移动它后要从第 2 步重新安装，更新定时任务路径。

## 源码与验证

仓库包含插件清单、钩子、控制器、设置与状态面板、Windows 安装入口以及测试。运行以下命令可在本地验证，不会启动你配置的正式任务：

```
python -m unittest discover -s tests -v
```

插件默认在指定工作目录使用 Codex 的 `workspace-write` 沙箱。任务若要借用当前 Windows 账号的 GitHub 登录状态，可能需要用户明确调整执行权限；插件不会自动提升权限或读取登录令牌。配置与运行日志保存在 `%USERPROFILE%\.codex\quota-watcher\`，不会随这个源码仓库发布。
